## 总述

### 前端具体项目大概介绍

本项目展示层面向医疗分析人员和管理者，负责将智慧医疗大数据分析结果以可视化和交互化方式呈现出来。人员5 直接承担前端三项功能建设：大屏可视化、聊天式 Web 交互界面以及二期可视化进阶。

前端需要接收后端分析服务返回的结构化 JSON 数据，以及 AI 交互模块返回的文字摘要与图表配置，并完成页面布局、图表渲染、交互联动、下载导出、加载状态、异常提示与空数据处理。

## 大屏可视化（一期）

### 功能的简单介绍

大屏可视化用于集中展示医疗数据核心指标与多维分析图表。页面需展示 KPI 卡片、疾病分布、支付方式占比、医院 TopN、费用与住院时长等结果，并支持按疾病、年龄、医院、年份等维度筛选联动，同时支持缩放和下载导出。

### 用例图

> 图3：大屏可视化用例图（原文档为图片）。

**参与者**：医疗分析人员 / 管理者、分析 API（人员3 提供）。
**用例**：加载默认指标与图表、选择分析维度、按维度联动查询、缩放视图、下载导出、异常/空态展示。

### 用例阐述

| 项目 | 内容 |
|---|---|
| 用例名称 | 大屏可视化 |
| 功能描述 | 用于展示医疗数据核心指标和图表分析结果，并支持筛选、联动、下载等操作。 |
| 前置条件 | 用户已进入系统首页；分析 API 可正常访问；默认数据可返回。 |
| 事件流 | 1）进入大屏页面后，系统加载默认指标与图表；2）用户通过筛选条件选择疾病、年龄、医院、年份等维度；3）前端向分析 API 发送请求；4）接收返回数据后，前端适配为 ECharts 可渲染格式；5）页面展示 KPI 与图表结果，并支持缩放、联动与下载导出；6）若接口异常或无数据，则展示异常提示或空数据页面。 |

## Web 交互界面（一期）

### 功能的简单介绍

Web 交互界面采用聊天式交互方式，用户通过自然语言输入医疗分析问题，前端负责展示消息列表、文字洞察、图表结果和报告内容，并支持继续追问形成连续对话体验。

### 用例图

> 图5：Web 交互界面用例图（原文档为图片）。

**参与者**：医疗分析人员 / 管理者、AI 智能交互模块（人员1 LangChain Agent）。
**用例**：自然语言输入、加载状态展示、消息列表渲染、图表/报告渲染、追问会话、异常重试。

### 用例阐述

| 项目 | 内容 |
|---|---|
| 用例名称 | Web 交互界面 |
| 功能描述 | 用于接收用户自然语言输入，并展示文字洞察、图表结果和报告内容。 |
| 前置条件 | 聊天接口可访问；AI 智能交互模块可正常返回文本与图表配置。 |
| 事件流 | 1）用户进入聊天页面；2）在输入框中输入问题并点击发送；3）前端展示加载状态，如"生成中""分析中"；4）接收返回的消息内容和图表配置；5）在消息区展示文字结果，在报告区展示图表与分析内容；6）用户可继续追问，前端保持会话展示逻辑；7）若接口失败或图表配置错误，则提示异常并支持重试或降级为文本展示。 |

## 可视化进阶（二期）

### 功能的简单介绍

可视化进阶功能在一期图表基础上新增地图、3D 图表和动态时序图等高级展示形态，用于更直观地表达医院分布、时间变化趋势以及复杂指标关系，并支持放大、筛选、下载和响应式展示。

### 用例图

> 图7：可视化进阶用例图（原文档为图片）。

**参与者**：医疗分析人员 / 管理者、二期增强分析 API。
**用例**：选择展示类型（地图 / 3D / 时序）、设置筛选、渲染增强图表、放大/切换视图、下载导出、降级处理。

### 用例阐述

| 项目 | 内容 |
|---|---|
| 用例名称 | 可视化进阶 |
| 功能描述 | 用于展示地图、3D 图表和动态时序图等高级可视化结果。 |
| 前置条件 | 二期增强数据接口可访问；地图和 3D 可视化能力可用。 |
| 事件流 | 1）用户进入进阶可视化页面；2）选择展示类型，如地图、3D 图表或动态时序图；3）设置筛选条件并请求增强分析数据；4）前端调用 ECharts 或 3D 插件渲染结果；5）用户可进行放大、切换视图与下载导出；6）若数据不足或性能不足，则页面降级为普通图表形式展示；7）若接口异常，则展示错误提示并支持重试。 |
